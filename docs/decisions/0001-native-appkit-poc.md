# 0001：先用原生 AppKit 验证视觉遮罩

日期：2026-11-04。状态：选定实验方向，兼容性未验证。

## 背景

系统锁屏后现有 Computer Use 无法继续工作。目标是在当前登录会话中让实体屏幕不可见，同时保留现有自动化能力。

## 选择

先做最小 Swift/AppKit 视觉覆盖窗口，配合现有 Computer Use 与独立 Safari 测试页面验证截图和坐标点击，再测试 Space/全屏覆盖。

采用 AppKit 是为了直接控制 NSWindow 层级、焦点、鼠标穿透和跨 Space 行为。首轮不实现密码、菜单栏或本地输入限制；不改系统认证，不引入第二登录会话。

## 代价与退出条件

视觉遮罩不建立系统锁屏的安全边界。鼠标穿透不能限制旁人输入；分享属性不保证对任意采集路径有效；工具激活应用可能破坏覆盖。这些均是需实测的条件。

若无法同时满足“实体遮挡持续有效”和“现有 Computer Use 截图、坐标点击可用”，暂停产品功能，重新评估遮挡或采集机制。只有辅助功能可用不能视为当前视觉方案通过。
