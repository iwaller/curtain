# Computer Use 兼容性验证

状态：普通遮罩、Safari 全屏及返回后的工具截图和坐标点击已测；UU 远程分阶段复测确认闪露，并捕获退出全屏动画中的桌面露页帧，持续遮挡失败。实体屏幕观察与普通 Space A → B → A 待确认。

## 职责与工具边界

使用现有 Codex Computer Use 对专用 Safari 页面执行截图与点击，验证遮罩和现有工作流的兼容性。项目不另写 Computer Use 客户端，也不通过浏览器 DOM、页面脚本或 AppleScript 完成点击后声称 GUI 通过。

本轮使用 `mcp__computer_use` 的 `get_app_state`（应用截图与辅助功能树）、`click`（截图像素坐标）、`press_key` 和 `type_text`（打开/关闭测试标签页和切换全屏）。CUA App Version 为 1001641。未使用 DOM、AppleScript 或页面脚本驱动测试点击。AppKit 应用不依赖这些工具的内部实现。

## 证据分层

| 证据 | 能说明什么 | 不能替代什么 |
| --- | --- | --- |
| 应用截图 | 工具能否看见 Safari 画面 | 实体屏幕是否仍被覆盖 |
| 辅助功能树 | 工具能否读取目标元素状态 | 视觉截图是否可用 |
| 截图坐标点击及计数回读 | 当前视觉坐标输入是否有效 | 本地输入是否被阻止 |
| 元素点击及计数回读 | 辅助功能操作是否有效 | 坐标输入是否有效 |
| 实体屏幕观察 | 遮罩是否可见、切换是否闪露 | Computer Use 能否采集或输入 |

若没有实体屏幕观察条件，先完成独立的工具侧检查，但最终结论只能是部分验证。

## 测试页面与隔离

专用页面显示大按钮、计数和足够明确的状态文字，点击只影响页面本身。每个场景记录起始计数和点击后的计数，避免以“工具返回成功”替代结果回读。

使用新的测试标签页，保持用户原有页面。只在需要时启动 loopback 静态服务，测试结束关闭服务和测试标签页。

## 验收和记录

按 [实验方案](../poc-plan.md) 顺序执行。遮罩开关、采集排除属性、Space 和全屏状态为显式变量；每次只改变必要条件。

记录工具调用是否激活目标应用，以及激活前、中、后的遮罩表现。黑色截图配辅助功能树可读，仍不能判定视觉任务通过。只记忆旧坐标点击也不算遮罩下视觉闭环。

实际结果归 [验证记录](../verification.md)。原始截图可能包含桌面内容，放入忽略的 `artifacts/`，文档只保留必要的脱敏观察。

## 本轮采集差异

普通 `.readOnly` 遮罩仍存在时，Computer Use 的 Safari 应用截图可读；`screencapture -x` 桌面截图近乎全黑（少量系统指示点）。两条路径分别保留证据，不推断工具内部机制，不将桌面截图当作连续实体观察。四次 GUI 坐标点击由页面计数 0 → 1 → 2 → 3 → 4 回读，详情见 [验证记录](../verification.md)。

## 远程观察边界

UU 远程观察单独作为证据层：用户早段确认黑屏，后半段报告自动恢复前出现测试页。进程在预定 90 秒到期退出，但没有连续观察证据定位首次露出时点，不能只凭个别全黑桌面帧否定用户反馈，也不能直接归因于全屏窗口属性。后续将稳定态与各个切换段拆开核验。详见 [UU 复测记录](../verification.md#2026-11-04uu-远程观察复测)。

后续 120 秒分阶段复测已捕获退出全屏动画中的桌面露页帧，并与仍运行的进程日志、操作时间及用户观察核对。该项已从“阶段未定位”推进到“至少退出全屏过渡会闪露”；每秒采样不能排除其他更短的露出，完整记录见 [验证记录](../verification.md)。

## 修复对照的采样要求

本轮对照采集为约 0.22–0.34 秒一帧；窗口轨迹约 40 毫秒一次。记录采集时间区间和进程在采集前后的存活状态，区分启动未覆盖、运行中露出和正常释放后的画面。统计非黑帧不能替代人工查看异常帧，也不能据采样间隔估算精确露出时长。用户未全程观察的轮次按缺证据记录。四项对照均失败，当前代码已回退，见 [验证记录](../verification.md)。
