# 需求分析与最小实验

## 目标与边界

用户直接锁定 macOS 后，现有 Computer Use 无法继续工作，希望获得“人看不到桌面，Codex 仍能操作”的锁屏体验。

第一步验证的是视觉隐私层：保留登录会话，在显示器上覆盖黑色窗口，尝试让现有 Computer Use 看见并点击底层 Safari。该实验不建立系统认证边界，也不验证密码安全。

需要拆开三个目标：实体屏幕不可见、Computer Use 可见可操作、本地人员不可操作。最小实验只解决前两个；点击穿透会同时放行本地鼠标，第三个目标需独立设计和验证。

## 为什么值得试、哪里仍不确定

原生黑色窗口易实现，也不需要第二套登录环境。若工具截取独立应用窗口且能向底层应用输入，视觉遮罩可能兼容现有工作流。

但“截图”可能指桌面合成、应用窗口或其他采集路径；不同路径可能对遮罩有不同表现。Computer Use 还可能为截图或点击激活、抬高目标应用，导致实体显示器露出内容。因此仅凭一张可读应用截图不能判断方案成功。

`NSWindow.sharingType = .none` 只能作为对照变量，不能预先承诺它在当前 macOS 或当前工具采集路径下有效。高窗口层级、跨 Space 属性和全屏辅助窗口也必须验证实际行为。

## 最小应用设计

计划一个手动启动的 Swift/AppKit 应用，每个连接显示器创建一个黑色不透明、无边框窗口，覆盖 `screen.frame`。通过合适窗口层级保持在普通应用上方，尝试跨 Space 和全屏辅助行为；不使用系统原生全屏创建单独 Space 来冒充全局覆盖。

窗口不成为 key/main window，避免抢走 Safari 的键盘焦点。初始模式设为鼠标穿透，专门验证既有输入通道。先实现有限时自动关闭（例如默认 90 秒，可配置）与进程退出清理，再开启遮罩。暂不做密码、菜单栏或键盘/鼠标拦截。

准备两个模式：普通黑色覆盖窗口作为基线；同样窗口增加 `sharingType = .none` 作为对照。若基线失败，可试一次对照确认方向，不无休止调高层级或添加锁屏功能。

## 实验步骤

### 0. 环境与恢复

记录 macOS、Swift、显示器数量/分辨率/缩放、Computer Use 工具名称及调用方式。检测构建工具，记录实际构建命令。先验证遮罩会自动关闭，并说明终止进程的办法。

Safari 打开专用无敏感内容的本地页面，页面提供大按钮和可见点击计数。若本地文件受限，再用仅监听 loopback 的临时静态服务。测试页面只改变自己的状态，不访问业务系统。

### 1. 无遮罩基线

使用现有 Computer Use 获取 Safari 状态，确认截图可读，记下测试按钮坐标。执行一次截图坐标点击，观察计数从 0 变为 1。必要时另测辅助功能点击，但单独记录。基线失败先处理工具连接或权限，不能归因于遮罩。

### 2. 普通遮罩

手动启动限时黑色遮罩。确认实体屏幕覆盖所有连接显示器，然后使用同一工具重新获取 Safari 状态。

分别记录：截图是页面、黑色还是报错；辅助功能树能否读到页面；取状态时是否激活 Safari、是否露出桌面。若页面可见，按当前截图坐标点击一次，回读计数，确认恰好增加 1。需要校验遮罩在点击瞬间与之后都保持覆盖。

若截图黑色，不能用遮罩前记住的坐标或仅靠辅助功能操作来宣布视觉工作流通过。可以把这些操作作为诊断，但必须与主验收分开。

### 3. 排除采集对照

若普通遮罩使截图不可用，保持其他条件一致，只把窗口分享属性改为 `.none`，重复第二步。分别记录两种模式；不得把其效果外推到未经测试的截图工具或系统版本。

若两种模式都无法同时满足实体遮挡与现有工具截图，停止密码、菜单栏等产品功能，转向重新选择遮挡或采集机制。

### 4. Space 与全屏

只有截图与点击初步通过后再做。分别测试普通 Space A → 普通 Space B → A，以及 Safari 进入原生全屏 → 返回桌面。每次切换后重新检查实体覆盖、截图和坐标点击。

切换过程也观察是否出现短暂内容泄露，不能只检查回到桌面的最后一帧。工具截图不是实体屏幕观察的替代证据；无法观察实体显示时，该项记为待人工确认。

### 5. 退出与恢复

确认超时能关闭全部遮罩；再单独验证主动结束 POC 进程后窗口消失。关闭专用测试标签页/临时服务，恢复本次改变的全屏与窗口状态，保留用户原有 Safari 会话。

## 判定

| 观察结果 | 结论与下一步 |
| --- | --- |
| 实体持续黑色，截图可读，坐标点击有效，Space/全屏检查通过 | 视觉隐私路线在当前环境初步成立；再评估本地输入限制 |
| 截图可读，但取状态或点击时实体屏幕露出内容 | 遮罩失效，不能进入产品功能阶段 |
| 实体黑色，截图黑色/报错，只有辅助功能可用 | 现有视觉工作流不通过；调整采集或遮挡机制 |
| 截图可读，但点击无效果或遮罩吃掉事件 | 输入路径未通过，先诊断激活/窗口/事件行为 |
| 普通桌面通过，Space/全屏切换失效或闪露 | 覆盖生命周期未通过，先修复覆盖策略 |
| 没有实体屏幕观察证据 | 只能报告工具侧结果，不能宣称隐私遮罩通过 |

首轮尽量控制在约十分钟的实验范围；系统权限、构建环境或观察条件不足时记录阻塞，不用推测填补结果。该时长为范围目标，不是当前完成承诺。
